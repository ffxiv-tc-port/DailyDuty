# DailyDuty

[DailyDuty](https://github.com/MidoriKami/DailyDuty) 的台服移植版。自動追蹤各項每日／每週任務進度的插件，適合容易忘記做每日／每週例行任務的玩家。指令 `/dd`。

不追蹤僱員（Retainer）或公會相關事項，那類需求請改用 Accountant。

## 支援的項目

- 理符任務
- 隨機任務
- 老主顧交易
- 天書奇談
- 假面狂歡
- 挑戰筆記
- 友好部族任務
- 怪物通緝令（每日／每週）
- 多瑪飛地
- 大國防聯軍：籌備軍需品、籌備補給品（每日），冒險者分隊任務（每週）；設定視窗裡這三項目前以「軍隊（…）」開頭
- 大型任務、團隊任務
- 時尚品鑑
- 仙人微彩、仙人仙彩
- 幻巧拼圖
- 寶物地圖

## 視窗

- 設定視窗（`/dd`）：逐模組開關與細項設定；設定管理器可管理各角色的設定
- 資料視窗：顯示每個模組目前記錄的資料
- 待辦清單與重置倒數計時：疊在遊戲畫面上的未完成項目清單與每日／每週重置計時
- 副本收藏品總表（`/dd collectables`）：列出各副本還缺哪些收藏品；在任務搜尋器選到副本時，視窗底部也會提示那個副本還缺的收藏品
- 完成的項目不會另外提示；尚未完成、且已可執行的項目會用聊天訊息通知，部分模組的通知訊息可點擊直接觸發對應動作

## 帶我去

部分項目有「帶我去」按鈕，按一下把你帶到目的地（傳送＋走到 NPC 或告示板前）。預設不會替你接任務或戰鬥：

- 怪物通緝令（每日／每週）：前往發那張通緝令的告示板；每週告示板可以站在板子前自己記位置
- 天書奇談、幻巧拼圖、多瑪飛地、假面狂歡、時尚品鑑、仙人微彩、仙人仙彩：前往對應的 NPC

隨時可以取消，進入戰鬥或副本也會停下；有裝 Lifestream 時用它傳送、沒有就用遊戲自己的傳送；有裝 vnavmesh 時自動走過去、沒有就只標地圖旗標。

## 怪物通緝令的討伐輔助

每週通緝令接了之後，同一頁的「告示板捷徑」可以按「前往目標地圖」或「巡邏重生點」：

- **一路做完**：傳送到目標地圖後接著依較短路徑巡邏已知的重生點，發現目標就先接近到設定的距離內再停。這兩段都可以關；偵測半徑與接近距離可調。
- **你操作就讓位**：途中自己操作角色會暫停，停手後接續（可改成一動就結束）；進入戰鬥或副本就停下。
- **打完自動前往下一張通緝令**（預設開）：你在這一頁按過出發之後，每打完一張通緝目標，等戰鬥結束、角色停穩就前往下一張：已接的先去目標地圖，沒有的話去下一張的告示板。手動移動、按取消或停止、又進入戰鬥或副本就停止接續。
- **抵達告示板後自動接取通緝令**（預設關）：到了告示板自動互動、選這一趟要接的那張並按下接受，每週的接到後直接前往目標。任何一步對不上（告示板不在可互動的距離、選單或通緝令視窗和預期不同、無法確認 YesAlready 不會同時按、出現確認視窗）就停下，視窗留給你自己處理。每日通緝令的告示板行程也適用。
- **接近通緝目標後自動開打**（預設關）：接近完成後選取那隻通緝目標並開自動攻擊，之後的出招交給戰鬥插件。只對這一張通緝令的目標、只出手一次，目標要可選取且在自動攻擊射程內；你已經選了別的目標或已在戰鬥中就不出手。人在坐騎上會先下坐騎。WrathCombo 的自動循環開著時，會先選取目標並請 WrathCombo 開打，幾秒內沒進入戰鬥才改開自動攻擊；沒開成時會停下並告訴你原因。

以上都只在你自己按了出發的那一趟（以及它的自動接續）裡生效；載入插件、登入、換區都不會自己開始。設定在設定視窗「怪物通緝令（每週）」頁的「巡邏設定」；每日通緝令頁只有自動接取這一項，兩頁共用同一份設定。

## 指令

- `/dd`：開關設定視窗
- `/dd collectables`：開啟副本收藏品總表
- `/dd todo enable`／`disable`／`toggle`：開關待辦清單
- `/dd timers enable`／`disable`／`toggle`：開關重置倒數計時

## 台服版的修改

- 介面繁體中文化，用語對齊台服官方譯名。
- 新增「帶我去」與怪物通緝令的討伐輔助（見上兩節），包含預設關閉的自動接取與自動開打。
- 討伐輔助只收回自己發起的傳送與移動，不會中止你或別的插件正在用的 Lifestream 傳送與自動移動。
- 開放唯讀的狀態 IPC（`DailyDuty.GetIncompleteModules` 等）：別的插件可以查詢還沒做完的項目並請它「帶我去」。
- 重置後仍有未完成項目時可請塔塔露誇獎念一句（預設開）；可在重置時發 Windows 系統通知（預設關，只在遊戲失焦時）。
- 清單型模組一項都沒選時改顯示「未知」，不再算「已完成」。
- 天書奇談的「重新貼」提醒在奇想點有 2 點時就響。
- 角色設定管理不再自動向 Lodestone 查角色，要查請在視窗上勾選。
- 設定檔讀不懂時先另存一份備份再重建，不直接蓋掉原檔。
- 某個項目載入失敗或特徵碼對不上時只跳過它自己，插件照常載入。
- 多處減少登入卡頓與記憶體用量。

## 需要搭配的插件

- 選用：[Lifestream](https://github.com/ffxiv-tc-port/Lifestream)、[vnavmesh](https://github.com/ffxiv-tc-port/vnavmesh)（「帶我去」與討伐輔助）、[WrathCombo](https://github.com/ffxiv-tc-port/WrathCombo)（自動開打時接手出招）、[TataruPraise](https://github.com/ffxiv-tc-port/TataruPraise)

## 安裝

`/xlsettings` 開「Dalamud 設定」→「試驗性功能」→「第三方插件倉庫」，加入 `https://raw.githubusercontent.com/ffxiv-tc-port/DalamudPluginsTC/main/repo.json` 並啟用、儲存，再到「插件管理員」（`/xlplugins`）安裝；同一個插件只裝這裡的版本，不要同時裝上游版。
