# DailyDuty

自動追蹤各項每日／每週任務進度的插件，適合容易忘記做每日／每週例行任務的玩家。指令 `/dd`。

不追蹤僱員（Retainer）或公會相關事項，那類需求請改用 Accountant。

## 支援的項目

- 理符任務
- 通關輪盤
- 老主顧交易
- 天書奇談
- 假面狂歡
- 挑戰筆記
- 友好部族任務
- 狩獵任務（每日／每週）
- 多瑪飛地
- 軍需品、分遣隊等軍隊理符相關事項
- 每週限定次數的大型任務、大國防聯軍剩餘可完成次數
- 時尚品鑑
- 仙人微彩、仙人仙彩
- 幻巧拼圖
- 藏寶圖

## 視窗

- 設定視窗（`/dd`）：逐模組開關與細項設定
- 資料視窗：顯示每個模組目前記錄的資料
- 完成的項目不會另外提示；尚未完成、且已可執行的項目會用聊天訊息通知，部分模組的通知訊息可點擊直接觸發對應動作

## 安裝

在 Dalamud 設定的「自訂插件庫」加入
`https://raw.githubusercontent.com/ffxiv-tc-port/DalamudPluginsTC/main/repo.json`
並啟用，再從插件列表安裝。
